# 攒股收息内容线

一个手机优先的纯静态内容生产小团。主理人输入选题，小数（数据）→ 小稿（写作）→ 小核（核对）各运行一次，最后由固定模板拼成稿件，交回主理人编辑、拍板、复制。不是交易工具，不提供投资建议。

## 本地运行

```sh
. ~/.nvm/nvm.sh && nvm use 24
npm ci
npm run dev
```

手机与电脑在同一网络时，访问终端显示的局域网地址。正式站点可直接用手机浏览器打开，建议添加到主屏幕。手机复制按钮需要 HTTPS；若复制不可用，可长按正文手动复制。

1. 打开「偏好设置」，填入自己的 OpenRouter 密钥，保存本地设置。
2. 默认模型为 `google/gemma-4-31b-it:free`；可载入实时 `:free` 列表或手动覆盖。默认名称不保证服务端始终可用。
3. 编辑十四只 A 股观察池，每行代码与名称。
4. 在创作工作台输入选题，启动协作。失败即停止；重试会新建一次完整运行，不会自动反复请求。
5. 展开数据快照查阅字段、来源和抓取时间，阅读规则核对与模型核对记录。编辑成稿，去除不用于发布的核对记录，确认披露后拍板，复制正文。

## 隐私与边界

API 密钥只保存在当前浏览器的 localStorage，不硬编码、不记录到历史或日志、不进入云端同步。密钥会作为鉴权头发送给 OpenRouter；选题、快照与草稿会发送到所选模型。公共行情和财务查询只发送股票代码，不携带密钥。浏览器本地存储并非加密保险箱，请勿在共享设备保存密钥。Google 字体不可用时自动使用系统字体。

设置及作品均仅在当前浏览器。清除网站数据会丢失内容，重要作品请另行复制备份。网络、跨域策略、免费模型额度和接口数据变化可能导致失败。拍板只是人工确认状态，不表示核对必然正确。规则核对是保守提醒（包括单字禁词与数字匹配），不能替代事实审查。

## 数据口径

- 腾讯 `qt.gtimg.cn` 行情按 GBK 解码，`~` 字段索引：1 名称、2 代码、3 现价、4 前收、30 时间、32 涨跌幅、39 市盈率、45 总市值（亿元）、46 市净率。
- 腾讯字段 64 经真实接口对比，表现与近十二月税前现金分红/现价相符，但没有依赖未公开字段定义。应用统一使用东方财富 `RPT_SHAREBONUS_DET`：最近一个自然年内，除权除息日已到、状态为「实施分配」的 `PRETAX_BONUS_RMB`（每十股派息）合计除以十，再除以腾讯现价乘百分之百。无已实施记录时为零；接口失败则停线，不伪造数值。该口径不是预测股息率，历史分红也不代表未来。
- 最新报告来自 `RPT_F10_FINANCE_MAINFINADATA`，保留报告期、营收、归母净利润、每股收益与 ROE。每字段展示来源与抓取时间；行情时间另列。财报金额按原始元存储。
- 数字核对支持四舍五入以及万、亿、万亿单位，不验证推导出的新数字；正文仅允许快照数字。小核同时向模型核对事实，风险项附于成稿后供人工处理。

## 架构扩展点

- `src/squads/types.ts`：Role、Squad，保留双 squad 标识元组的 MidSquad 类型，未实现中团组合。
- `src/squads/registry.ts`：注册 `zangu-shouxi`，新增小团可复用流水线。
- `src/pipeline/runner.ts`：通用顺序运行器，单步状态/输入/输出/错误/时间与进度回调，输入不含密钥。
- `src/storage/index.ts`：RunStorage 接口、LocalStorageRuns 实现和明确抛错的 SupabaseRuns 占位；未安装 Supabase 依赖。设置独立于作品存储，日后接云端也不应同步密钥。

## 检查与部署

```sh
npm test && npm run build
npm run smoke
VITE_BASE_PATH=/content-squad/ npm run build
```

烟测是 Node 直接请求三个真实股票接口，不使用密钥；单元测试不需要外网。Node 通过并不等于浏览器跨域永远可用。

创建远端仓库后，将源码推到 `main`，在仓库 Settings → Pages 的 Source 选择 **GitHub Actions**。工作流先测试构建，再通过 `actions/deploy-pages` 发布，子路径默认 `/content-squad/`。自定义域名或仓库改名需调整工作流的 `VITE_BASE_PATH`。本项目当前不含远端，也未部署。
