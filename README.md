# 攒股收息内容线

一个手机优先的纯静态内容生产小团。主理人输入选题，小数（数据）→ 小稿（写作）→ 小核（核对）各运行一次，最后由固定模板拼成稿件，交回主理人编辑、拍板、复制。不是交易工具，不提供投资建议。

## 本地运行

```sh
. ~/.nvm/nvm.sh && nvm use 24
npm ci
npm run dev
```

手机与电脑在同一网络时，访问终端显示的局域网地址。正式站点可直接用手机浏览器打开，建议添加到主屏幕。手机复制按钮需要 HTTPS；若复制不可用，可长按正文手动复制。

1. 打开「偏好设置」，填入自己的 OpenRouter 密钥，保存本地设置。
2. 默认模型为 `google/gemma-4-31b-it:free`；可载入实时 `:free` 列表或手动覆盖。默认名称不保证服务端始终可用。
3. 编辑股票池，每行代码、名称及“持仓”或“观察池”；未标记的视为观察池。默认严格为四只持仓（中国平安、兴业银行、海尔智家、云南白药）及十只观察股（招商银行、伊利股份、工商银行、宁沪高速、长江电力、美的集团、中国神华、中国移动、中国联通、港股中海油 00883）。仅旧版默认池的精确副本自动迁移，任何自定义池保持不变。
4. 在创作工作台输入选题，启动协作。失败即停止；重试会新建一次完整运行，不会自动反复请求。
5. 展开数据快照查阅字段、来源和抓取时间，阅读规则核对与模型核对记录。保存新股票池后会收起旧快照，需要重新运行；每次运行仅读取已保存的池，不使用未保存的编辑。历史快照不会自动重抓。编辑成稿，去除不用于发布的核对记录，确认披露后拍板，复制正文。

港股使用五位代码，通过腾讯 `hk` 行情查询，价格及市值明确标为港元/亿港元，不与人民币混用。东方财富港股财报按返回币种展示；未提供手动分红的港股分红及股息率仍显示“缺失”，不使用未经验证的腾讯字段 64。财报字段空缺同样显示“缺失”，不视为零。可用 `npm run smoke` 检查默认全部 14 只，也可在末尾传入代码。

每行可追加 `分红TTM=1.49港元`（A 股用 `元`）提供近十二月每股现金分红，金额须非负、币种须与行情一致；它覆盖该代码的接口分红，股息率按手动金额 ÷ 腾讯现价 × 100% 计算。默认池的 `00883 中海油 观察池 分红TTM=1.49港元` 使用主人提供的 1.49 港元。快照界面及传给小数、小稿、小核的数据均标注「主人手动提供」，不冒充接口核实的分红或税前口径。仅精确匹配旧版 14 股默认池或上一版四持仓十观察默认池时自动迁移；自定义池（包括未标记手动分红的 00883）不改动，历史快照不回填。

## 隐私与边界

API 密钥只保存在当前浏览器的 localStorage，不硬编码、不记录到历史或日志、不进入云端同步。密钥会作为鉴权头发送给 OpenRouter；选题、快照与草稿会发送到所选模型。公共行情和财务查询只发送股票代码，不携带密钥。浏览器本地存储并非加密保险箱，请勿在共享设备保存密钥。Google 字体不可用时自动使用系统字体。

设置始终仅在当前浏览器。未配置云端或未登录时，作品也仅在当前浏览器；登录后，新的作品保存与历史读取使用云端，不自动合并或上传本地记录。退出后恢复本地历史。清除网站数据会丢失本地内容，重要作品请另行复制备份。网络、跨域策略、免费模型额度和接口数据变化可能导致失败。拍板只是人工确认状态，不表示核对必然正确。规则核对是保守提醒（包括单字禁词与数字匹配），不能替代事实审查。

## 可选云端存储

构建时同时提供 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_PUBLISHABLE_KEY`。后者必须为 `sb_publishable_` 开头的公开发布密钥，可安全包含在静态构建中；不要提供任何管理权限密钥。缺少配置或仍为占位符时自动使用纯本地模式。

1. 管理员检查后，在 Supabase SQL Editor 以 `postgres` 管理员身份执行 `supabase/migrations/0001_runs.sql`。本次开发没有执行迁移或任何线上写入。
2. 由管理员建立邮箱密码账号，关闭不需要的公开注册。应用只有登录，没有注册入口。
3. 管理员通过 SQL 向 `public.app_owner(user_id)` 写入允许访问的 Auth 用户 UUID。空名单时无人能读写作品。客户端对名单无表权限；名单启用并强制 RLS，无客户端策略。名单只能由管理员 SQL 管理。
4. `private.is_app_owner()` 是固定空搜索路径、无参数的稳定安全定义者函数，由 `postgres` 所有，仅向已登录用户开放执行；`private` 不应加入 API 暴露 schema。作品表按当前用户及名单双重限制，更新同时检查旧行和新行。
5. 在手机「偏好设置 → 云端同步」登录，显示当前邮箱；作品档案自动切换到云端。退出恢复本地档案，不删除任一端的数据。切换账号会清空当前编辑视图，避免误存到另一存储。

密码只在登录请求中提交，应用不自行保存密码。Supabase 会在本浏览器保存会话令牌以维持登录；共享设备用完请退出。OpenRouter 密钥及股票池偏好不写入云端，云端 `data` 仅保存运行记录（快照、稿件与核对过程）。请不要主动在选题或正文里填写密钥。网络保存失败时请先复制稿件备份，没有自动离线回写。

## 数据口径

- 腾讯 `qt.gtimg.cn` 行情按 GBK 解码，`~` 字段索引：1 名称、2 代码、3 现价、4 前收、30 时间、32 涨跌幅、39 市盈率、45 总市值（亿元）、46 市净率。
- 腾讯字段 64 经真实接口对比，表现与近十二月税前现金分红/现价相符，但没有依赖未公开字段定义。未配置手动覆盖的 A 股使用东方财富 `RPT_SHAREBONUS_DET`：最近一个自然年内，除权除息日已到、状态为「实施分配」的 `PRETAX_BONUS_RMB`（每十股派息）合计除以十，再除以腾讯现价乘百分之百。无已实施记录时为零；接口失败则停线，不伪造数值。该口径不是预测股息率，历史分红也不代表未来。
- 最新报告来自 `RPT_F10_FINANCE_MAINFINADATA`，保留报告期、营收、归母净利润、每股收益与 ROE。每字段展示来源与抓取时间；行情时间另列。财报金额按原始元存储。
- 数字核对支持四舍五入以及万、亿、万亿单位，不验证推导出的新数字；正文仅允许快照数字。小核同时向模型核对事实，风险项附于成稿后供人工处理。

## 架构扩展点

- `src/squads/types.ts`：Role、Squad 与 MidSquad。工作台可选择小团，或「攒股收息 × AI手记」中团：先攒股收息三步，再 AI手记三步，最后合并数字复核。两团共享已保存设置与同一份快照，仅首次取数；各自简报、正文及核对独立。合并时攒股正文在前、AI手记正文在后，以分隔线连接，保留各段声明和披露，核对记录统一附在文末。切换内容线会收起当前稿件（已保存历史不变）；刷新默认选择小团。
- `src/squads/registry.ts`：注册攒股收息、AI手记及三个银行小团。`midRunner` 支持 N 个小团按配置依次执行，每团三步后合并数字复核，合并正文和核对记录使用各团段名；复核使用按代码去重的全部快照。新小团首步在自身快照为空时继承前团快照，数据角色可复用或重新取数；原「攒股收息 × AI手记」仍共享一次取数。「银行中团」依次执行四大行、股份制银行、城商银行，共十步，各自仅抓取固定的 4/8/6 家银行，不改用户股票池；沿用池中分类与手动分红，池外银行标为未持有，既不是持仓，也不代表主人的观察池。
- `src/pipeline/runner.ts`：通用顺序运行器，单步状态/输入/输出/错误/时间与进度回调，输入不含密钥。
- `src/storage/index.ts`：RunStorage 接口、LocalStorageRuns 与 SupabaseRuns 实现。云端按用户过滤、创建时间倒序读取，以运行 id 执行 upsert。设置独立于作品存储，不同步模型密钥。
- `src/storage/supabase.ts`：可选构建配置、客户端与中文错误；`src/CloudSettings.tsx`：邮箱密码登录与退出。

## 检查与部署

```sh
npm test && npm run build
npm run smoke
VITE_BASE_PATH=/content-squad/ npm run build
```

烟测是 Node 直接请求三个真实股票接口，不使用密钥；单元测试不需要外网。Node 通过并不等于浏览器跨域永远可用。

仓库 Settings → Pages 的 Source 选择 **GitHub Actions**。工作流先测试构建，再通过 `actions/deploy-pages` 发布，子路径默认 `/content-squad/`。自定义域名或仓库改名需调整工作流的 `VITE_BASE_PATH`。部署工作流已填写项目 URL 和公开发布密钥（publishable key，设计上可公开；service_role/secret key 绝不放进前端或仓库）。云端历史只有写入 `app_owner` 表的账号能读写，公开注册和匿名登录已关闭。
